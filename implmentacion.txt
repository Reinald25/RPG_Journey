# RPG Journey — Auditoría + Sistema de Misiones (Template Method)

## Resumen del Proyecto Actual

RPG Journey es un juego RPG por turnos en Java con interfaz Swing. El jugador elige una clase (Guerrero, Mago, Asesino, Tanque, Curandero, Soporte), combate enemigos aleatorios, gestiona un inventario con pila (Stack), gana XP, sube de nivel y puede enfrentarse a Jefes (Boss).

## 🏗️ Diseño del Sistema de Misiones — Template Method

### Clase Abstracta: Mision.java

El *Template Method* define el flujo fijo *Inicio → Desarrollo → Fin* y delega los pasos específicos a las subclases.

java
package com.rpg.mision;

public abstract class Mision {

    private String nombre;
    private String descripcion;
    private EstadoMision estado;

    // ══════════════════════════════════
    //  TEMPLATE METHOD (flujo fijo)
    // ══════════════════════════════════
    public final void ejecutar(Personaje jugador) {
        estado = EstadoMision.EN_PROGRESO;
        iniciarMision(jugador);          // Hook obligatorio
        boolean exito = desarrollarMision(jugador); // Hook obligatorio
        finalizarMision(jugador, exito); // Hook obligatorio
        estado = exito ? EstadoMision.COMPLETADA : EstadoMision.FALLIDA;
    }

    // ══════════════════════════════════
    //  Métodos abstractos (subclases)
    // ══════════════════════════════════
    protected abstract void iniciarMision(Personaje jugador);
    protected abstract boolean desarrollarMision(Personaje jugador);
    protected abstract void finalizarMision(Personaje jugador, boolean exito);

    // ══════════════════════════════════
    //  Hook opcional (puede sobreescribir)
    // ══════════════════════════════════
    protected void onRecompensa(Personaje jugador) {
        // Sin recompensa por defecto
    }
    
    // Getters ...
}


### Enum: EstadoMision.java

java
public enum EstadoMision {
    PENDIENTE, EN_PROGRESO, COMPLETADA, FALLIDA
}
